# SEO Review

Review what a search engine and a shopper can discover without relying on client-side assumptions.

## Checklist

- Inspect route titles, descriptions, canonical URLs, robots directives, sitemap availability, and indexable product/category pages.
- Check server or build-time rendering limitations in this React app and identify where metadata is actually emitted.
- Check product names, descriptions, headings, links, image `alt` text, fallback images, and stable URLs.
- Check structured data opportunities and validity for products, offers, breadcrumbs, organization, and reviews.
- Check redirects, 404 behavior, duplicate query URLs, and mobile performance signals.

## Output

Report findings with URL/route, file/line, search impact, and a practical fix. Do not claim search-engine behavior without inspecting the generated HTML or deployment configuration.
