# Журнал продолжения работы

Этот файл — переносимый контекст для продолжения работы над DreamShopVo на другом устройстве. Он намеренно не содержит паролей, токенов, ключей или персональных данных.

## Как продолжить

1. Клонировать репозиторий и перейти в ветку `main`.
2. Открыть проект в Codex. Правила проекта находятся в `AGENTS.md`, локальные навыки — в `.agents/skills/`.
3. Прочитать `MASTER_REBUILD_PLAN.md` и продолжить с первого незакрытого пункта. Отмечать пункт выполненным только после проверки.
4. Перед работой проверить `git status --short`; не перезаписывать чужие изменения.

## Последнее состояние

- Последний сохранённый коммит: `8937a41` (`chore: preserve local agent workspace guidance`).

## Проверки, выполненные до журнала

- Для кода storefront/admin выполнены тесты, typecheck и production build на соответствующих этапах работы.
- В отдельном staging-окружении успешно проверены browser-сценарии создания и отмены тестового заказа. После отмены заказ получил статус `cancelled`, а повторная отмена стала недоступна.
- Временные staging-данные ещё требуют отдельного явного подтверждения пользователя перед удалением: тестовый пользователь, созданный им заказ и сохранённый адрес. До подтверждения их не удалять.

## Ограничения синхронизации

GitHub сохраняет исходный код, инструкции, документы и историю коммитов. Он не сохраняет историю интерфейсного чата Codex, сеансы браузера и глобальные плагины приложения. После входа в тот же аккаунт Codex плагины подключаются в самом приложении; проектные инструкции и навыки уже есть в репозитории.
