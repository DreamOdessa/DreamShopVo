# Старый интерфейс: локальный режим просмотра

Старый React-интерфейс можно открыть вместе с административной областью без подключения к Firestore и без изменения правил рабочей базы:

```bash
npm run start:legacy-preview
```

Откройте `http://localhost:3004/admin`.

Режим включается только переменной `REACT_APP_LEGACY_LOCAL_PREVIEW=true`, которую задаёт эта команда. Он использует вымышленные товары, категории, клиентов и заказ, предоставляет локального администратора и не делает запросов за данными к рабочей Firestore. Все операции записи в Firestore и загрузка файлов в Cloudinary в этом режиме намеренно заблокированы.

Не добавляйте эту переменную в Vercel, Firebase Hosting или другой публичный build. Это инструмент визуальной проверки и миграции старого интерфейса, а не способ получить доступ к рабочим данным.
